# Exécuteur d'algorithmes

Application pour écrire des algorithmes en français, les exécuter pas à pas, suivre les variables et voir l'organigramme s'animer.

- **Télécharger pour Windows** : voir les [Releases](../../releases/latest).
- **Essayer en ligne** : la version web est dans `site/app/`.

## Contenu du dépôt

| Dossier / fichier | Rôle |
|---|---|
| `Exécuteur d'algorithme.html` | l'application (un seul fichier HTML) |
| `desktop/` | version de bureau Electron et création de l'installateur (voir `desktop/LISEZMOI.md`) |
| `site/` | site de présentation, publié automatiquement sur GitHub Pages |

## Fonctionnalités

Pas à pas et lecture automatique, organigramme animé, variables et table de trace, tableaux et matrices, Si / Selon / Pour / Tant que / Répéter, fonctions et procédures (paramètres `Var`, récursivité), messages d'erreur expliqués, fichiers `.algo`.
